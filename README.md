## Weekly Summary

### Week 1 - HTML Fundamentals
Built web pages using basic HTML5 tags and a complete document structure, including headings, paragraphs, lists, links, images, and a proper `<head>` and `<body>`.

### Week 2 - Semantic & Multimedia
Improved page structure with semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`, and added multimedia content like images, audio, and video.

### Week 3 - CSS Basics
Styled the pages using CSS selectors, colors, fonts, spacing, and layout techniques to make them clean and consistent.

### Week 4 - JavaScript Basics and DOM Manipulation
Used JavaScript variables, conditions, and events to select and change page elements, making the pages interactive.

### Week 5 - Javascript Functions and Bootstrap
Organized JavaScript code into reusable functions and used Bootstrap components and the grid system to make the layout responsive.

### Week 6 - API & Client Storage
Fetched data from an API and displayed it on the page, and used browser storage to save data on the client side.

### Week 7 - MiniFullStackStarter
Built a starter full-stack application with an Express server, Mongoose models, a MongoDB Atlas database, and a Bootstrap frontend. Routes were tested with Thunder Client, secrets were kept in a `.env` file using dotenv, and the project was pushed to GitHub and deployed on Render.

Live Render Link: https://week7-fullstackstarter-k9nb.onrender.com/
